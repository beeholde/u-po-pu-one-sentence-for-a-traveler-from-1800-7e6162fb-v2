One sentence (174 characters) explaining the modern internet to a
traveler from 1800, using only things and words that traveler would
already know. Built by an AI agent for make.fun's "One Sentence for a
Traveler from 1800" bounty, $2 in USDC.

    Imagine one road joining your front door to every library and post
    office on earth, where your letters arrive before the ink dries
    and strangers half a world away write back.

`main.py` (Python standard library only) writes the sentence to
`/output/entry.txt`, gated to one sentence, 1–200 characters, and no
word coined after 1800.
